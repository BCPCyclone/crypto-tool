Hinweise
Fakt: Kurse, EMA, RSI, ATR, MACD werden aus den geladenen Kerzen berechnet.
Signal: EMA-Kreuzungen, Trendregime.
Szenario: Fibonacci und Volatilitätskegel sind Orientierung, keine Prognose.
Aktien: Yahoo Finance (ohne Einrichtung über öffentlichen Proxy, stabiler mit eigenem Proxy unter ⚙), ersatzweise Twelve-Data-Key. 4H bei Aktien ist aus Stundenkerzen zusammengesetzt.

Fundamentaldaten und Nachrichten kommen inoffiziell von Yahoo (nicht für jeden Titel verfügbar); die Nachrichtenstimmung ist eine grobe Stichwort-Schätzung.

Keine Anlageberatung. Alle Angaben ohne Gewähr; Handel birgt das Risiko des Totalverlusts.

Einstellungen

Eigenen Proxy einrichten
1. Konto auf dash.cloudflare.com anlegen.
2. Workers & Pages → Create → Create Worker → Deploy → Edit code.
3. Alten Code löschen, den kopierten Code (Version 3) einfügen, Deploy. Nach App-Updates den Code erneut einfügen.
4. Die Worker-URL oben eintragen.
